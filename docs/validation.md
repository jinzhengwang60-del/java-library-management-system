## 38 项 HTTP / MySQL 集成测试

在初次发布的 17 项基础上增加 21 项回归检查。覆盖内容包括：

- 登录页、验证码、错误验证码与错误密码、受保护页面、注册和公开地区接口。
- 图书查询、关键词搜索、管理员与普通读者权限。
- 正常借还、重复借阅、无库存、越权归还、重复归还、最后一本书的并发竞争。
- 借书或还书期间主动注入库存更新失败，验证借阅记录与库存一起回滚。
- 无效、停用读者不能借阅。
- 读取页面实际渲染的 CSRF 表单字段提交登录；缺失或伪造凭证不能改变库存。
- GET 退出返回 405 且保留会话，POST 正常退出。
- 正确登录才升级旧 MD5；错误登录保持原摘要不变。
- “记住我”恢复会话、HttpOnly 与签名格式、篡改拒绝、密码变化使旧 Cookie 失效。
- 资料中的 HTML 与 JavaScript 特殊字符不能作为页面代码输出；图书列表、详情、编辑页转义用户内容。
- 极大和负数页码正常渲染；含 `&` 的关键词在翻页链接中正确编码。
- 管理员打开旧编辑页后发生借阅，旧保存返回 409，已减少的库存保持不变。
- 合法编辑成功，负库存和重复馆藏编号不能保存。
- 图书下架保留借阅记录、停止新借阅，已借图书仍可归还。
- 停用账号保留历史，撤销其现有会话与持久登录；管理员账号受到保护。
- 同一账号的两个会话合并显示在线，刷新资料不丢失状态，退出其中一个不影响另一个。
- 真实图片即使使用 JSP 文件名，也只保存并返回随机名称 PNG；文件位于 Web 根目录之外。
- 伪装成 PNG 的脚本被拒绝；超大图片使用请求头或普通表单均返回 413。
- 版本冲突时删除本次已保存的新图片，不留下孤立文件。

测试不增加绕过验证码的公开接口。验证码值和表单凭证来自测试容器的 Session；另有一项登录测试使用真实 HTML 中的表单字段。

## 旧数据库升级

另建隔离测试数据库，导入初始发布提交中的旧 `sql/booksys.sql`，然后连续执行两次新升级脚本。

- 旧数据共 4 个账号、6 个分类、15 本图书、4 条借阅。
- 对每张表按 ID 排序，读取所有原字段的 JSON 表示并比较 SHA-256。
- 第一次升级、第二次升级后，所有原字段值及行数均与升级前一致。
- 密码字段长度为 255，新增图书版本列全部默认为 0。
- 三个新增索引存在，脚本重复执行成功。

本项只验证数据库结构和数据，不包含旧上传图片迁移。
