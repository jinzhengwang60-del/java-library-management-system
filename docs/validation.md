# 发布验证记录

日期：2026-10-15，北京时间。

## 实际环境与结果

- Windows，Eclipse Temurin JDK 11.0.32.1，Maven 3.6.3。
- 本机 MySQL 8.0 程序建立独立测试实例，仅监听本机专用端口。
- 测试数据目录、随机生成的密码及私有配置均保存在仓库外部。
- SQL 初始化：4 张表、4 个虚构账号、6 个图书分类、15 本图书。
- JUnit 5 + 嵌入式 Tomcat 9.0.123，真实执行 HTTP、JSP 和数据库操作。
- Maven verify：17 项集成测试，失败 0，错误 0，跳过 0；WAR 打包成功。

## 17 项测试

1. 登录页和验证码图片。
2. 错误验证码不能获得登录权限。
3. 正确验证码配合错误密码仍被拒绝。
4. 图书分页和关键词搜索返回结果。
5. 未登录访问受保护页面跳转登录页。
6. 未登录注册页面可以读取省份列表。
7. 借还书同时更新库存和记录，重复归还不增加额外库存。
8. 普通读者不能归还他人的书。
9. 无库存时不生成借阅记录。
10. 同一读者不能重复借阅未归还的书。
11. 两个读者并发争抢最后一本书，只有一个成功。
12. 注入库存更新失败时，插入的借阅记录回滚。
13. 归还期间库存更新失败时，归还状态回滚。
14. 无效读者触发外键失败，不消耗库存。
15. 管理员可查看全部借阅记录，普通读者被拒绝。
16. 新注册的虚构读者可登录并访问个人中心。
17. 清除会话 Cookie 后，记住登录状态可恢复会话。

## 验证边界

这里记录的是 Windows/JDK 11 上的实际运行。其他 Java 版本和操作系统由 GitHub Actions 单独验证，不能将配置的矩阵当作已通过的结果。

未进行生产压力测试、全站安全审计或完整浏览器视觉验收。原有 MD5、记住登录状态和上传文件实现仍有改进空间。

发布工作在独立副本中完成，原项目的整理前后校验值另行核对并保存在本机。
